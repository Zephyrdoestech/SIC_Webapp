# SIC Webapp

The Social Impact Catalyst (SIC) - CIT-U Chapter website: a university-wide platform for discovering initiatives, collaborating across student organizations, and showcasing contributions toward the UN Sustainable Development Goals.

## Planned features

- SIC information, publications, and event highlights
- University-wide SDG project and event tracker
- Impact dashboard based on approved records
- Organization submissions and administrator review
- Membership, registration, feedback, and partnership opportunities

## Development

Planned stack: React, Vite, and Tailwind CSS. Development starts locally with mock data and simulated roles. Supabase integration and deployment come later, after validation and explicit approval.

The project is currently in planning; the application has not been scaffolded yet.

See [PRODUCT.md](PRODUCT.md) for requirements and constraints. Supplied brand assets are in [ASSETS](ASSETS/).
